# Табло игры «Рабочий день за 60 минут»

Отдельная страница с рейтингом столов и итогами для экрана в зале. Результаты приходят со стенда GigaCowork: движок игры после каждой команды отправляет сюда свою строку «ЗАПИСЬ». Строки подписаны движком, поэтому подделанный результат сервер не примет.

## Страницы

- `/` — табло. Обновляется само каждые 4 секунды. Когда на стенде запускают `/финал`, страница сама переключается на итоги.
- `/final` — итоги, всегда.
- `/api/state` — рейтинг в JSON.

## Приём результатов

- `POST /api/push` с телом `{"zapis": "<строка движка>", "final": false}`. Строку можно передавать вместе с окружающим текстом: сервер сам найдёт в нём строки `ST..|...` и `GAME|...`.
- `POST /mcp` — то же самое через MCP (Streamable HTTP). Инструменты: `zapisat_rezultat` и `pokazat_tablo`.
- Если два ноутбука одного стола сдают одновременно, ответы складываются и не затирают друг друга.
- Новая игра: когда приходит команда `/запуск` больше чем через час после предыдущей, столы прошлой игры убираются.

## Переменные окружения

- `TABLO_SALT` — ключ подписи из движка `igra.py`. Обязательно. Без него сервер не примет ни одного результата.
- `ADMIN_TOKEN` — нужен для `POST /api/reset` (очистить табло) и `POST /api/mode` (`{"final": true}` — показать итоги), заголовок `Authorization: Bearer <токен>`.
- `TABLO_DB` — путь к файлу базы. По умолчанию в контейнере это `/tmp/tablo.db`.

## Render

В корне репозитория лежит `render.yaml`. Порядок: New → Blueprint → выбрать репозиторий → ввести `TABLO_SALT` → Apply. На бесплатном тарифе сервис засыпает через 15 минут без запросов, просыпается примерно за минуту. Диск там не постоянный. Это не страшно: движок каждый раз присылает полный счёт стола, и табло восстанавливается само.

## Локально

```
pip install -r requirements.txt
TABLO_SALT=... ADMIN_TOKEN=... uvicorn app:app --port 8000
```
